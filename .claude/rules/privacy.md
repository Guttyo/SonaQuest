# プライバシーと公開情報のルール

## 利用者のデータ
### 保持・送信・保存・ログ出力の違い
| 言葉 | 意味 | 扱い |
|---|---|---|
| 保持 | その回の間だけ、ブラウザのメモリに持つ（結果画面に原文で返すため） | 初回画面で、その回の間だけ持つことと、タブを閉じたら消えることを知らせたうえでしてよい |
| 送信 | 会話を進めるために、Claude・音声合成（ElevenLabs）・音声認識（ブラウザが使うサービス）へ送る | 初回画面で送り先と目的を知らせたうえでしてよい。送るものは必要な範囲に限る |
| 保存 | データベース・ストレージ・ファイル・ブラウザの保存領域（`localStorage`・IndexedDB・Cookie など）に残す | しない |
| ログ出力 | `console.log` 等や、Workers のログに出す | 公開する版ではしない。手元の開発中だけ、既定でオフの切り替えをオンにしたときに限る（下） |

- 会話本文、録音、文字起こしを、自アプリのDB・ストレージ・ファイルに残さない（DBは持たない）。
- **公開する版（デプロイした Workers。本番・プレビューとも）と、本番用にビルドしたブラウザのコードでは**、`console.log` 等に会話本文・音声・プロンプト・Claudeの応答を出さない。出してよいのは件数、所要時間、エラーの種類など本文を含まない値だけ。
- 手元の開発中（`npm run dev`、`wrangler dev` など）に限り、確認のために本文を出してよい。出す仕組みは既定でオフにし、デプロイした環境では必ずオフになるようにする（仕組みは ADR-0007 の「開発中だけのログ出力」）。開発中に出した本文を、ファイル・Issue・PR・コミット・dev-log に貼らない。
- Cloudflare Workersのログ設定（Workers Logs／observability、`wrangler tail`）を確認し、決めた設定を `docs/decisions.md` ADR-0007に記録する。
- ブラウザ側も `localStorage` 等に会話を保存しない。タブを閉じたら消える状態を保つ。
- 例外：ボードの掲示板チャット（B-07、訓練の流れの外のデモ。ADR-0047）。2026-11-06 にオーナーがチャットで、会話の履歴が Anthropic 側のセッションに残ることを聞いたうえで Managed Agents を選んだ。人が本部として書いた架空の書き込みと、エージェントの文は、Anthropic の Managed Agents のセッションの履歴に残る。アプリは保存しない（画面の状態はブラウザのメモリだけ）。送る前に、架空の訓練用であることと、送り先と、そこに残ることを画面に出し、実在の人の名前や実際の情報を入れないよう案内する。訓練（患者向け）の会話は Managed Agents に送らない。使ったセッションを消すかどうかは ADR-0047 のマーカー。
- 例外：ボードのカルテの抽出型の要約と監査（B-10、訓練の流れの外のデモ。ADR-0052・ADR-0053、2026-11-06 オーナー決定「採用する」）。ブラウザは架空の会話の見本の ID だけを Worker に送り、Worker が見本を Messages API に送って要約させる。監査は Managed Agents のセッションで行い、送るのは架空の会話の見本と要約だけ。監査のセッションは1回ごとに作って毎回消すが、消すまでは Anthropic 側のセッションに残る。訓練の会話とボードのカルテの入力は送らない。ログに出すのは失敗の種類・件数・所要時間・セッションの後片付けの状態だけで、会話・要約・指摘の本文は出さない（ADR-0007）。
- 例外：HQ のカルテ画面の文字起こしの要約（Issue #202、訓練の流れの外のデモ。ADR-0061 の追記、2026-11-07 オーナー決定「着手して」、同日「要約も進める」）。文字起こしは、オーナーが架空の患者を演じて話す見本。文字起こしの文はブラウザのメモリだけに持ち、保存しない。利用者が確かめの欄に印を付けて「要約を作る」を押したときだけ、その時の文字起こし（2000字まで）を Worker（`/api/karte/transcript-summary`）に送り、Worker が Messages API に送って要約させる。監査役（Managed Agents）には送らない。送る前に、送り先（Workers を通して Anthropic の Claude）と、架空の内容だけを送ることを画面に出す。訓練の会話とボードのカルテの入力は送らない。ログに出すのは失敗の種類・件数・所要時間だけで、文字起こし・要約の本文は出さない（ADR-0007）。音声そのものはブラウザの音声認識の事業者にだけ送られ、Worker・Claude には送らない。
- 外部API（音声認識、音声合成、Claude）に送るものと、各事業者の保持方針を初回画面で示す。**自アプリの方針と外部事業者の方針は分けて書く**。
- APIキーはWorkersのsecretsで管理し、ブラウザに出さない。ブラウザから外部APIへ直接つなぐ必要がある場合は、短命トークンの方式をADRで決める。

## 公開リポジトリに書かないこと
- 制作者の勤務先と、それを推測できる情報
- 制作者の職業や経歴（READMEのプロフィール欄は `[TODO-OWNER]`）
- 実在の人物の情報
- オーナーの作業予定や生活の様子
- 検出したい語はオーナーが `.claude/local/blocklist.txt`（gitignore済み）に書く。Claude Codeはこのファイルを読まない。コミット前フックと編集前hookが照合し、該当しても語そのものは表示しない。
