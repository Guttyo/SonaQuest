# safety-review

対象：今回の差分（`git diff` と未コミットの変更）。基準は `.claude/rules/safety.md` と `.claude/rules/privacy.md`。

## 1. 禁止出力
- プロンプトやコードが、薬剤名・用法・用量・病名の推定、正誤判定、服薬の助言、診断、備蓄量の助言を生む余地を持っていないか
- 利用者の発言を要約・言い換え・創作して表示していないか（結果画面は原文表示）
- 公的制度の説明を生成していないか（固定文と出典のみ）
- 緊急入力で訓練が中断し、固定の案内が出るか
- Claudeの出力を検査せず画面に出す経路がないか

## 2. 外部送信
- 送信先は音声認識・音声合成・Claudeだけか。新しい送信先が増えていないか
- 送る内容は必要最小限か。初回画面の説明と一致しているか
- APIキーがブラウザ側のコードやビルド成果物に入っていないか（`VITE_` 接頭辞の環境変数に秘密を置いていないか）

## 3. ログと保存
- `console.log` 等に会話本文・音声・プロンプト・応答を出していないか
- `wrangler.toml`／`wrangler.jsonc` の observability 設定が ADR-0007 と一致しているか
- `localStorage`・IndexedDB・Cookieに会話を残していないか

## 報告
問題ごとに「場所（ファイル:行）／何が起きうるか／直し方」を書く。問題がなければ、何を確かめたかを書く。安全上の判断が要るものは `[TODO-OWNER]` としてオーナーに渡し、自分では決めない。
