# 外部レビュー・助言の記録（reviews）

外部の監査や、別のAIモデル（Claude Fable など）から受けた助言を、受けたときの形で残す場所。どの助言を受けて、どう直していったかを後から追えるようにする。

## ほかの記録との違い

| 記録 | 書くこと |
|---|---|
| `docs/reviews/` | 外から受けた助言そのもの（何を聞き、何を言われたか） |
| `docs/decisions.md` | 助言を受けて決めたこと（決定・理由・却下案・影響） |
| `docs/dev-logs/` | 決めるまで・直すまでの経過と教訓 |
| `docs/KEEP-THINKING.md` | 作業1回ごとの短い日誌 |

## 書き方
- **助言は決定ではない。** 採用したものは ADR やIssueに書き、記録の「採用と対応」の節から番号で参照する
- 冒頭に、日付、助言したもの（モデル名など）、読んだ版（コミット）、聞いたことを書く
- 助言の文面は、なるべく受けたままにする。助言の中の事実の主張は、使う前に元のファイルで確かめる
- CLAUDE.md 絶対ルール8の情報（勤務先、職業・経歴、実在の人物、作業の予定や生活の様子）、作業の時刻、アカウント名、秘密情報は載せない。そのために言い換えた箇所は、記録の冒頭に書く
- ファイルはリポジトリからの相対パスで書く。手元の絶対パス（ユーザー名やフォルダの名前を含む）は載せない。書き出した後に `C:\`・`/Users/` などで検索して確かめる
- オーナー判断のマーカーに触れる文は、角かっこを外して「TODO-OWNER マーカー」と書く（本物のマーカーとして数えられないように）

## ファイル名
`YYYY-MM-DD-<助言したもの>-<テーマ>.md`（英小文字とハイフン）。日付は助言を受けた日。
