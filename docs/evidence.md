### 実験計画：固定質問方式とClaude対話方式の比較
- 目的：同じ回答に対して、Claudeを使うと何が変わるかを数字で示す。
- 材料：架空の回答セット 10件 [TODO-OWNER: 回答セットの内容を確認]。曖昧な回答、観点が抜けた回答、情報源が使えない回答、緊急の訴えを含む回答を混ぜる。Claude Codeが下書きし、オーナーが確認する。実在の情報は使わない。
- 正解：各回答セットについて、5観点の3段階（確認できた／未確認と気づいた／確認していない）をオーナーが事前に付ける [TODO-OWNER: 正解ラベル]。
  - → オーナー（2026-11-02、チャット）：7・8は後で実施。架空回答10件はClaude Codeが作り、正解ラベルはオーナーが確定する。MVP骨格の後、実験の前までに決める。

### 回答の上限を10回にした後の訓練の時間（Issue #41。2026-11-04）
- **目的**：回答の上限を最大10回（前半5回・後半5回、固定の質問は半分ごとに4問）にした版で、本物の Claude を使って訓練を通し、1回にかかる時間と、聞き返しの枠の使われ方を見る。
- **方法**：オーナーの承認（2026-11-04、チャット）のもと、手元の Workers（`wrangler dev`、Opus 5.5・effort low。モデルの切り替えはしない）と開発用サーバーを、Claude desktop のブラウザ画面（Chromium）からつないだ。架空の回答で3回通した。回答は Claude Code がページの中から入力したので、人が文を読む時間と入力する時間は入っていない。応答時間はブラウザの記録（Resource Timing）で測った。会話の本文はどこにも残していない。
- **結果**：

| | 1回目 | 2回目 | 3回目 |
|---|---|---|---|
| 経路 | ふつうに答える。③確認はお薬手帳（初期選択も同じ） | 曖昧な答えで聞き返しを起こす。③確認はスマートフォン（初期選択なし） | 思い出せない答え。③確認で選ばずに進む（係の交代） |
| 回答の数 | 8（前半4・後半4） | 10（前半5・後半5） | 8（前半4・後半4） |
| 聞き返し | 0回 | 3回（前半1・後半2） | 0回 |
| 省かれた固定の質問 | なし | 後半の最後の問い（思い出せなかったこと） | なし |
| Claude の返事を待った時間の合計 | 23秒 | 41秒 | 26秒 |
| 通しにかかった時間（入力は即時） | 42秒 | 71秒 | 34秒 |
| 聞き取り係の文の字数（固定文を含む） | 604字 | 703字 | 867字 |
| 利用者の回答の字数 | 224字 | 130字 | 152字 |
| 5観点の判定 | 確認できた5 | 確認できた5 | 確認できた3、未確認と気づいた2 |

  - 呼び出しは26回で、すべて成功した（失敗・時間切れ・固定の進行への切り替えは0回）。応答時間は中央値2.6秒、最大6.8秒。5秒を超えたのは26回中6回（後半の、入力が多い呼び出しに多かった）。8秒の待ち時間は超えなかった。
  - Claude の文が禁止表現の検査で捨てられ、固定文に戻ったのが1回（2回目の後半の聞き返し）。
  - 2回目では、前半は聞き返し1回と固定の4問で5回の枠を使い切り、後半は聞き返しが2回入って、最後の固定の質問を聞かずに振り返りへ進んだ（設計どおり）。
  - 3回目では、思い出せない答えの直後に、その場の固定文が出た。
  - ストレージは空で、コンソールにエラーは無かった。料金は、1回 約 $0.008 の見積もりで、26回で約 $0.21。
- **人が通したときの時間（見積もり。測っていない）**：上の通しには、読む時間と入力する時間が入っていない。仮に、読む速さを1分あたり400〜600字、スマホの文字入力を1分あたり30〜60字とすると、聞き取り係の文と場面・出来事・③確認の文（約860〜1,130字）を読むのに約1.5〜3分、回答（130〜224字）を文字で入力するのに約2〜7.5分、Claude を待つのに約0.4〜0.7分かかる。文字で答えると約4〜11分になり、「約3分」に収まらない見込み。音声で答える場合と、考える時間は見積もっていない。速さの値は仮定で、出典は無い。人が実際に通して測る必要がある。
- **限界**：回数は3回だけ。回答は Claude Code が書いた架空の内容で、短め。人が読む・考える・入力する時間は測っていない。応答時間はその日の API の混み具合で変わる。
