### 実験計画：固定質問方式とClaude対話方式の比較
- 目的：同じ回答に対して、Claudeを使うと何が変わるかを数字で示す。
- 材料：架空の回答セット 10件 [TODO-OWNER: 回答セットの内容を確認]。曖昧な回答、観点が抜けた回答、情報源が使えない回答、緊急の訴えを含む回答を混ぜる。Claude Codeが下書きし、オーナーが確認する。実在の情報は使わない。
- 正解：各回答セットについて、5観点の3段階（確認できた／未確認と気づいた／確認していない）をオーナーが事前に付ける [TODO-OWNER: 正解ラベル]。
  - → オーナー（2026-11-02、チャット）：7・8は後で実施。架空回答10件はClaude Codeが作り、正解ラベルはオーナーが確定する。MVP骨格の後、実験の前までに決める。
- 方式A（固定質問）：決まった6問を順に出す（前半3問 → 確認 → 出来事 → 後半3問。ADR-0019）。聞き返しなし。判定は語の照合。
- 確認（タップ）は、回答セットに「本人が確かめる情報源」を用意し、両方式で同じものを使う。
- 方式B（Claude対話）：聞き返しをClaudeが行い、観点をClaudeが判定する。
- 出来事は両方式とも同じルールで選ぶ（ADR-0016）。条件をそろえて比べるため。
- 回答者の動き：回答セットに「聞き返されたときの答え」も用意し、同じ台本で両方式を回す。

### モデルの比較（ADR-0006。2026-11-04）
- 目的：同じ問い合わせで、Opus 5.5・Sonnet 5.5・Haiku 5.5（どれも effort low）を比べる。上の「方式A と方式B の比較」とは別の実験。
- 材料：`web/experiments/cases.mjs`。架空の回答で、次の18件。
  - judge 5件：6回の回答をそろえた最後のやり取りで、5観点の判定を見る。
  - behave 13件：1問目への1回の回答で、緊急・思い出せない・次の手を見る。safety-test-plan の S・E の文を使う。
  - 期待の値は Claude Code の下書きで、オーナーは未確定（`[TODO-OWNER]`）。下の一致率は「下書きのラベルとの一致率」。
- 方法：手元の Workers（`wrangler dev`、比較実験の切り替え `DEV_EXPERIMENT` は手元だけで効く）に、`node web/experiments/run.mjs` で送った。1件1回、1モデル18回。結果は `web/experiments/results/`。Claude の文は結果に残さない。
- 料金は、使ったトークン数と参照資料の単価（2026-10 時点）からの見積もり。

| 指標 | Opus 5.5 | Sonnet 5.5 | Haiku 5.5 |
|---|---|---|---|
| 判定の一致（judge、5件×5観点） | 25/25 | 24/25 | 24/25 |
| 緊急・思い出せない・次の手の一致（behave） | 19/19 | 19/19 | 19/19 |
| 応答時間（中央値／最大） | 2.7秒／6.2秒 | 1.8秒／3.5秒 | 3.6秒／4.8秒 |
| Claude の文が検査を通った割合 | 11/13 | 12/13 | 13/13 |
| 失敗・別のモデルでの答え直し | 0・0 | 0・0 | 0・0 |
| 18回の料金（見積もり） | 約 $0.144 | 約 $0.067 | 約 $0.007 |

- 一致しなかったもの：
  - Sonnet J4：「記録が最新かは確かめていません」と答えたのに、観点③を「確認できた」とした。
  - Haiku J5：係の交代の後の「財布のメモを見せます」を、観点②（代わりの手段）として数えなかった。
- 検査で捨てられた文：Opus と Sonnet の「ゆっくりで大丈夫です」など。安心させる判断の語（大丈夫）に当たったが、医療的な判断ではない。捨てても固定文に戻るだけ。
- 緊急（E1・E2）では、どのモデルも中断の種類を正しく返した。画面は中断するので、そのときの Claude の文は出ない。
- 1件ずつ1回だけの試しで、件数が少ない。モデルの選び直しの根拠にするには、件数と繰り返しを増やす必要がある。今の決定（Opus 5.5、effort low。ADR-0006）は変えていない。
- **システムプロンプトを直した後**（ADR-0029。2026-11-04、Opus 5.5・effort low で同じ18件、約 $0.14）：
  - 一致は 44/44 のままだった。
  - Claude の文は 17/17 が検査を通った（直す前は 11/13）。
  - 半分の最後の5件では、5件とも受け止めの一言が出た（直す前は0件）。
  - 応答時間の中央値は2.7秒、最大は6.1秒。
  - 結果：`web/experiments/results/opus-5-5-low-prompt2.json`。
- この比較の前に、開発用サーバーで訓練を1回通した（Opus 5.5、8回の呼び出し。うち2回は試し方の誤りで文字化け）。そのときの料金は $0.08 だった（オーナーが Anthropic の画面で確かめた額）。
