# PRD：SonaQuest（ソナクエスト）

## 課題
災害時、普段頼っているお薬手帳やスマートフォンが手元にない・使えない場面で、自分の服薬情報を救護所で伝えられない人がいる。多くの人はその場面を一度も想像したことがない。

## 対象
常用薬のある一般の成人。医療者向けではない。

## 目的
約3分の音声対話で、発災翌日の避難所の救護所を疑似体験し、次の2つに気づいてもらう。
- 普段の情報源が使えないときの代わりの手段
- まだ確認できていないこと

薬の正誤を判断することは目的にしない。

## 体験の流れ（MVP）
1. 初回画面：訓練の説明、架空の場面であること、外部APIへの送信先と保持方針（自アプリと外部事業者を分けて表示）、緊急時は訓練でなく119等へ
2. 場面の導入：発災翌日、避難所の救護所。係の人（2Dキャラクター）が話しかける
3. 対話：利用者の回答は最大6回。音声優先、文字入力も可。曖昧な回答には聞き返す
4. 想定外の出来事：回答に応じて1回（例：スマートフォンの電池が切れる）。候補は固定で用意し、Claudeが選ぶ [TODO-OWNER: 出来事の候補一覧]
5. 結果画面：5観点の「確認できた／確認できなかった」と、利用者の回答（原文のまま）
6. 準備行動を1つ選んで終了 [TODO-OWNER: 準備行動の選択肢]

## 確認する5観点
1. 情報がどこにあるか
2. その情報源が使えないときの代わりの手段
3. 今の服用状況と、記録が最新か
4. 記録に載っていない可能性のある情報
5. 本人が説明できないときに代わりに伝えられる人

## 要件
- 目安3分。時間で強制終了しない
- ログインなし。会話を永続保存しない
- API失敗時も固定の質問で最後まで終えられる
- 緊急対応が必要な入力では中断し、固定の案内を出す
- iPhone Safariで動く

## 成功の目安（審査向けの測定は docs/evidence.md）
- 試した人が、確認できていなかった観点を1つ以上言える
- 禁止出力（薬剤・病名の推定、助言、診断）が試験で0件
