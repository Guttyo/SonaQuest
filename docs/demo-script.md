## 2026-11-05 の案：防災の背景から入り、訓練を主役に、本部のボードへつなぐ

### 決め方の提案
- **主役は「お薬の避難訓練」**。提出の必須（A）で、審査の「安心してそのまま使える」に直接応える。ボードは「訓練の出口が、災害のときの本部の判断につながる」ことを示す後半の見せ場にする（提出版は架空データのデモ。ADR-0042、ADR-0043）。

- **英訳を考えた話し方**：1文を短くし、数字には出典を添え、日本語の固有の言葉（お薬手帳、救護所、避難所）は最初に一度だけ短く言い換える（例：お薬手帳＝薬の記録の手帳）。言葉遊びや省略は使わない。画面の文字は日本語のままでよいが、ナレーションは直訳しやすい文にする。

## Cowork 向けの撮影の手順（2026-11-06）

Cowork（Claude がアプリを操作する）に渡す手順。目的は「操作の記録」ではなく「魅力が伝わる動き」なので、**1画面1判断、押す前に1拍、押した後に2拍**を守る。ナレーションは後から当てるので、画面の変化が止まってから次へ進む。

### 準備
- **録るのは再デプロイ後の公開 URL**（審査員が触る画面と同じもの）。手元で撮るときは `npm --prefix web run dev`（5173）と `dev:worker`（Claude と ElevenLabs）を起こす。Workers が無いと固定の質問で進み、振り返りの判定は「判定できませんでした」になる。
- 声の ID：撮影の前に、アプリ用の声の ID を本人の声から既製の声に替えておく（上の「声の割り当て」。オーナーの操作）。
- 画面の大きさ（2種類）：
  - 訓練（S1〜S9）：**幅 390px・高さ 844px** 相当のスマホ幅。Remotion 側でスマホの枠に入れて横長の画面に置く。
  - ボード（S10〜S12）：**1920×1080**（幅 1280px 以上）。
- 録画の設定：30fps。マウスカーソルは映してよいが、動かす距離を短く、速度を一定に。画面の音（アプリの声）も録る（S2 の1問目と S6 の立て直しの問いで使う。物語の構成では、ソナの問いをアプリの声で聞かせるため）。
- 物語の構成（2026-11-06 改訂）では、**S2 から S6 までを 3D で通して撮る**（文字で答える。マイクは使わない）。3D が公開 URL で本物の Claude と声で通らないときは、これまでどおり S3 以降を 2D で撮り、4番の録画の音は使わない（台本の表の注記）。
- アプリの **BGM は切ったまま**（初期状態はオフ。押さない）。
- 入力する文は上の表の文だけ。実在の薬の名前・人の名前・電話番号は入れない。言い間違えても直さない（アプリは正誤を判定しない）。
- 1回で通しを撮り、Remotion で使う場面だけを切る。失敗したら「訓練をやめる」で止めず、ページを読み込み直してはじめからやり直す（中断の画面を動画に残さないため）。
- 前半の 4問 → 情報源の確認 → 出来事 → 後半の 4問 → 振り返り → 準備行動、の順で、合計 8回答。所要は未計測（入力の時間を含めた見積もりは約4〜11分。docs/evidence.md「回答の上限を10回にした後の訓練の時間」）。Cowork が通した時間を測って、ここに実測を書く。
