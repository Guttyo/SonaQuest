## 2026-11-05 の案：防災の背景から入り、訓練を主役に、本部のボードへつなぐ

オーナーの要望（2026-11-05、チャット）：自己紹介の後に日本の地震の背景と「避難訓練はしても、薬のことは？」の問いを入れる。見る人は日本人だけではないので、英訳されることを考え、日本の災害の背景を入れつつ、SonaQuest の利点がすっと入る話にする。本部のボード（B-04〜B-06）とのつなぎ方と、どちらが主役かを決める。

### 決め方の提案
- **主役は「お薬の避難訓練」**。提出の必須（A）で、審査の「安心してそのまま使える」に直接応える。ボードは「訓練の出口が、災害のときの本部の判断につながる」ことを示す後半の見せ場にする（提出版は架空データのデモ。ADR-0042、ADR-0043）。
- **つなぎは「記録の形」**。訓練の振り返りに出る「救護所に渡す記録の形」（B-05）と、ボードのカルテの項目（薬の名前・量・処方元、飲めていない日数、記録の在りか、代わりに伝えられる人）が同じ。「平時に練習した伝え方が、そのまま災害時の記録の形になる」と一言で言える。
- **英訳を考えた話し方**：1文を短くし、数字には出典を添え、日本語の固有の言葉（お薬手帳、救護所、避難所）は最初に一度だけ短く言い換える（例：お薬手帳＝薬の記録の手帳）。言葉遊びや省略は使わない。画面の文字は日本語のままでよいが、ナレーションは直訳しやすい文にする。
