# デモ動画の台本（枠）

- 長さ：3分以内
- 映すのは期間中（2026-11-02 12:00 JST以降）に作った機能だけ
- 字幕・ナレーションはすべて日本語
- 人物と情報はすべて架空。画面に実在の薬剤・人物・医療機関を出さない

見せたいことの中心は、情報源を失った後に伝え直す「立て直し」の場面（docs/PRD.md「体験の核」、ADR-0019）。体験の通しでは、ここに一番時間を使う。

| 時間 | 画面 | 話すこと | 示す審査項目 |
|---|---|---|---|
| 0:00–0:20 | ① はじめに | 冒頭の問いかけ「あなたの薬のことを、どう伝えますか」（ADR-0022）。「お薬の避難訓練」の紹介と訴求文「もしもの時、自分の薬のことを伝えられますか？」。課題 | インパクト |
| 0:20–0:45 | ② 問い → ③ 確認 | 光のキャラクターに、普段の薬をどう伝えるか答える。デモでは架空の人物として演じ、その人物「自身の」準備として答える（薬の中身は「A薬」のような明らかな仮名。実在の人の情報やオーナー自身の準備は映さない。上の「人物と情報はすべて架空」のとおり）。頼っている情報源をタップで確かめる | デモ |
| 0:45–1:00 | ④ 出来事 | 確かめた情報源が使えなくなる（例：スマホの電池切れ） | デモ |
| 1:00–1:30 | ⑤ 立て直し | 「では、ほかにどうやって伝えられますか？」に、残った手段で答え直す | デモ |
| 1:30–1:50 | ⑥ 結果 | 手薄なところ（5観点の3段階）と回答の原文（出来事の前後）。点数は付けない。思い出せなかったことは「今ここで確かめましょう」（実際のお薬手帳や薬の袋の確認と、定期的な訓練での復習）。準備行動を1つ選ぶ | デモ、インパクト |
| 1:50–2:20 | | Claudeがしていること／しないこと | Claudeの活用 |
| 2:20–2:45 | | 安全とプライバシーの仕組み | 深さと実行 |
| 2:45–3:00 | | まとめ | |

画面の欄は docs/PRD.md「体験の6段階と実装の画面」の段階。実装の画面は「はじめに／対話／振り返り」の3つに決まっており（ADR-0019）、対応は ① はじめに＝はじめに、② 問い〜⑤ 立て直し＝対話、⑥ 結果＝振り返り。

撮影前に judge-audit を行い、未検証の主張を台本から外す。
