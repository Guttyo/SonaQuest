# 訓練の文の検査のすり抜けを塞ぐ（Issue #292）

- 日付：2026-11-11
- 対象：Issue #292（訓練の中で Claude が作った文の検査 `web/worker/checks.ts`）
- 関係する ADR：ADR-0012（検査に通らなければ固定文に戻す）、ADR-0025（Claude が作ってよい文）、ADR-0030（監査役）

## 背景

2026-11-11 のコードだけを対象にした静的な評価で、`checks.ts` の照合に、すり抜ける形と一度も当たらない禁止表現が見つかった（Issue #292 の本文）。どれも、残る守りが監査役だけになる形で、重さは低とされた。あわせて、プロンプトで頼む字数と検査の上限の食い違いと、ファイルをまたいだ定義の重なりが挙がった。

## やったこと

- 照合用の文を作る `textForMatch`（NFKC にかけ、空白と書式文字 `\p{Cf}` を除く）を足し、禁止表現の照合・`maskEchoed`・`normalize` で使った。利用者の言葉を取り出す `watchedWords` は、書式文字だけを除き、空白は言葉の切れ目として残した。
- 書式文字を含む文は、それだけで `forbidden` として捨てる守りを重ねた（質問文と振り返りの一言の両方）。
- `unknownTerms` は、空白と書式文字を除いた文から言葉を探し、中黒で1文字ずつ区切ったカタカナ（3文字以上）も返すようにした。許す言葉とは、固定の文から同じ決まりで取り出した言葉の集まりと丸ごと比べる（部分一致をやめた）。
- 禁止表現の「では？」を `では[?？]` に直した。
- 復唱で許す4つの禁止表現を名前の付いた定数にし、`ECHOABLE_PATTERNS` を番号でなく名前で作った。`FORBIDDEN_PATTERNS` の並びと中身は同じ。
- 文の長さの定数を `web/src/flow/turnContract.ts` に足し、システムプロンプトの字数・検査・ブラウザの応答の確かめで同じ定数を使った。
- `QUESTION_TEXT`・`QUESTION_EXAMPLES` を `web/worker/questions.ts` に移し、`buildUserMessage` は計画を引数で受け取る形にした。`parseClaudeOutput` のキーは `CLAUDE_OUTPUT_SCHEMA.properties` から作り、usage の詰め替えは `claude.ts` の `toUsage` にまとめた。

## つまずいたことと教訓

- 許す言葉を丸ごとの一致で比べるとき、直前の回答を空白を除いてから許す言葉に足すと、「ロキソニン カロナール」のように空白で分けて2つ挙げた回答が1つの言葉になり、片方の復唱が捨てられる。今までは部分一致だったので表に出なかった。次に許す側の比べ方を厳しくするときは、許す側の文の切れ目（空白）を残すかどうかを先に決め、空白で分けた回答の復唱を試験に入れる（`web/worker/echo.test.ts` に足した）。許す側は、空白を残したものと除いたものの両方から言葉を取り出す形にした。
- 振り返りの一言の上限を、Issue の例（100字程度）のまま決めかけた。決まった言い回しと観点の名前を正しくつないだ2文の一言を、判定のすべての組み合わせで作って測ると、最長は 126 字（係の交代の回は 100 字）で、100 字では正しい一言まで捨てる。次に長さの上限を決めるときは、正しい文を組み立てる試験を先に書いて最長を測ってから決める（`web/worker/turn.test.ts` の「文の長さの上限と、システムプロンプトの字数」）。
- システムプロンプトの字数を定数から差し込むとき、文字列が変わっていないことは、試験の文字列の照合だけでは確かめきれない。変更の前後でプロンプトの文字列をファイルに書き出し、ハッシュが同じことを確かめた。

## 確かめたこと（2026-11-11、Windows 11、Node.js 26.13、Vitest 5.1）

- `npx tsc --noEmit`：エラーなし
- `npx vitest run --maxWorkers=2`：60 ファイル・1142 件がすべて通った（変更前は 1107 件）
- システムプロンプトの文字列：変更の前後で SHA-256 が同じ
- 本物の Claude を呼んでの確かめはしていない（Claude の文が捨てられる割合が変わったかは測っていない）

## 推測

- 許す言葉の部分一致をやめたので、Claude が固定の言葉を短くした言い方（「スマートフォン」を「スマート」など）を使った文は、固定文に戻るようになる。固定の質問文とその受け止めの組み合わせが通ることは試験で確かめたが、実際の Claude の言い直しで戻る割合が増えるかは、本物で測るまで分からない。

## 残ること

- 禁止表現に、ひらがなの書き方などの語を足すか（Issue #292 の「オーナーの判断が要る点」1）
- 「では？」の直しで新たに捨てられる文の範囲の確認（同じく 2。PR でオーナーが確かめる）
